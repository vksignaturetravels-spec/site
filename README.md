# VK Signature Travels

Static site for one-way / round-trip / drop taxi enquiries across Tamil Nadu (and nearby hill stations). WhatsApp-led booking; Netlify publishes `dist/`.

## Local preview

```bash
npx serve dist -l 4173
```

## Regenerate route pages

```bash
python scripts/generate-routes.py
```
